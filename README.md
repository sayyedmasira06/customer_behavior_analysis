# Data Analytics Project - Customer_behavior_analysis

## Overview

This project focuses on analyzing a dataset to uncover meaningful insights and present them through interactive visualizations. The workflow covers data exploration, cleaning, SQL-based analysis, dashboard development, and business reporting.

The goal was to transform raw data into actionable insights that can support data-driven decision-making.

---

## Tools Used

* Python (Pandas)
* MySQL
* Power BI
* Gamma
* Jupyter Notebook

---

## Project Workflow

### Data Loading & Exploration

* Imported the dataset into Python.
* Reviewed data structure, data types, and overall quality.
* Performed Exploratory Data Analysis (EDA) to identify trends, patterns, and anomalies.

### Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Standardized and transformed data where required.
* Prepared a clean dataset for analysis.

### SQL Analysis

* Loaded data into relational databases.
* Wrote SQL queries to answer business questions.
* Used joins, aggregations, filtering, and window functions to generate insights.

### Dashboard Development

* Built an interactive Power BI dashboard.
* Designed visualizations to track key metrics and trends.
* Added filters and slicers for better user interaction.

### Reporting & Presentation

* Documented findings in a detailed analytical report.
* Created a presentation using Gamma to communicate insights and recommendations.
